# Code Kata

## Média Ponderada

Dado um objeto aluno com a propriedade nome e uma propriedade notas, com cada nota sendo um número absoluto e seu peso na média (porcentagem), crie um método que calcule a média ponderada do aluno.

```js
const aluno = {
    nome: "Márcia",
    notas: {
        n1: {
            nota: 8,
            peso: 0.2
        },
        n2: {
            nota: 7.5,
            peso: 0.5
        },
        n3: {
            nota: 9.2,
            peso: 0.3
        }
    }
}
```
