# Rede Social

## 1. Menu suspenso

Estilize o menu suspenso (3 pontinhos) para que se comporte como um menu suspenso no post. O menu deve ser acionado e escondido ao se clicar nos 3 pontinhos.
- Estilize o menu com as propriedades CSS de posição, z-index e display apropriadas para que ele fique flutuando sobre o container de post
- Utilize o método `addEventListner()` para atribuir evento aos elementos desejados

## 2. Comentários

### 2.1 Contagem de comentários

Realize a contagem de comentários existentes em cada publicação para exibir, usando JavaScript, o número correto, substituindo o número fictício presente no HTML.

**Dica**: você pode utilizar as funções da API do DOM para selecionar uma coleção e propriedades, como `length`, para contabilizar quantos elementos existem.

### 2.2 Colapsar comentários

Exibir os comentários de forma colapsada (escondidos), inicialmente, exibindo-os quando o usuário clicar em comentar ou no número de comentários.

### 2.3 Adicionar comentário

Implemente a funcionalidade de adicionar um novo comentário quando o usuário preencher o input e clicar no botão enviar, adicionando um novo comentário no conteiner de comentários e atualizando a contagem de comentários.
