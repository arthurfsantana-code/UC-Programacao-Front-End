# Países

## 1. Lista de países

Neste exercícios iremos praticar a inserção de múltiplos elementos a partir de uma estrutura de dados. A partir do array com a lista de nomes de países em `countries.js`, insira uma `<div>` com um título `<h3>` com o nome de cada país dentro.

### Passo a passo
- Percorra o array de países
- Para cada item do array, crie um novo elemento `<div>`e um `<h3>` com o conteúdo com o nome de cada país
- Insira o novo nó HTML na página, na posição desejada

## 2. Lista de países com cor

Modifque o exercício agora para utilizar o arquivo `countries-colors.js`, que possui um array de objetos de países, com nome e cor, exibindo agora o nome do país e adicionando a cor de fundo de cada país ao background da `div`.

## 3. Lista de países com detalhes e bandeiras

Agora iremos utilizar um array de países com objetos com mais detalhes, a partir do arquivo `countries-api.js`. Exiba as seguintes informações dos países (de maneira formatada, com HTML semântico):

- Nome
- Sigla
- Região
- Capital

Além disso, utilize a FlagCDN para exibir a bandeira dos países: [https://flagcdn.com/](https://flagcdn.com/)

## 4. Filtro de continentes

Adicione um array no topo do seu script com os valores `["América", "África"]`. Exiba apenas os países destes continentes.
Conseguindo, altere os continentes na lista para validar que está funcionando adequadamente.
